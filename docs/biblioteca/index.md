# Biblioteca científica

La **Biblioteca científica** reuneix textos per llegir, consultar i recuperar durant la realització de les activitats de Biologia, Geologia i Ciències Ambientals.

A diferència dels materials guia, que expliquen els coneixements de les unitats didàctiques, les lectures d'aquesta biblioteca serveixen com a **fonts de treball i de consulta**.

Un mateix text podrà ser útil en diferents activitats i no haurà d'estar vinculat necessàriament a una única unitat.

## Lectures

**Encara no hi ha textos publicats en aquest apartat.**

A mesura que incorporem lectures, les enllaçarem des d'aquest índex amb informació sobre la font i, quan correspongui, sobre les adaptacions o traduccions.
