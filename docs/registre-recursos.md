# Crèdits i procedència dels recursos

L'[inventari visual](inventari-visual.md) identifica individualment els **100 fitxers gràfics** que consten al repositori en la revisió inicial. La seva presència al web no demostra que tots siguin creacions originals ni que comparteixin una mateixa llicència.

| Conjunt | Estat de la procedència i dels drets |
|:--|:--|
| [Figures de la UD01](registre-figures-ud1.md) | Fitxers identificats; autoria i fonts externes pendents de comprovar individualment. |
| [Figures de la UD02](registre-figures-ud2.md) | Diagrames, models i altres recursos; les dades o imatges reals incorporades s'han de verificar. |
| [Figures de la UD03](registre-figures-ud3.md) | Figures sobre evolució, biodiversitat i història de la vida; procedència individual pendent. |
| [Figures de la UD04](registre-figures-ud4.md) | Esquemes de microbiologia; no es consideren microfotografies reals sense font acreditada. |
| [Infografies de programació](registre-figures-programacio.md) | Set infografies identificades separadament de les figures de les unitats. |
| Programari i eines externes | MkDocs, MathJax, biblioteques i complements mantenen les llicències dels seus titulars. |
| PDF i elements gràfics incrustats | Revisió dels components interns pendent; no pressuposa una única llicència per a tot el PDF. |

## Criteris per acreditar la procedència

Cada figura hauria de disposar de les dades següents: ruta del fitxer, tipus de representació, origen (inclòs l'ús d'IA si n'hi ha), autor o font, llicència, escala o advertiment quan correspongui i estat de revisió.

La nova automatització de GitHub només **detecta fitxers i publica fitxes**. Quan no hi ha dades comprovades, marca el registre com a «pendent de revisió» sense inventar informació.

**Estat inicial:** s'han identificat els fitxers del repositori, però no s'ha completat la verificació científica i jurídica individual de tots els recursos.
