# Infografies de programació

Infografies del calendari de la programació (UD01–UD07). No són les figures dels materials de les unitats. Aquest registre inclou **7 fitxers gràfics**. S'indiquen els fitxers i les comprovacions encara pendents, sense pressuposar autoria o llicència.

Cada element es classifica inicialment com a **pendent de revisió**. Una vegada documentada la font, l'ús d'IA si escau, els drets i les limitacions d'escala, l'estat s'actualitzarà des de les fitxes de procedència.
