# Llicències de BGCA

Aquest projecte aplica una **llicència doble** exclusivament a les aportacions pròpies sobre les quals es puguin concedir drets:

- **Continguts didàctics originals:** [CC BY-SA 4.0](LICENSE-CONTINGUTS.md).
- **Codi informàtic original:** [MIT](LICENSE-MIT).

S'exclouen els recursos de tercers, logotips institucionals, programari extern i qualsevol element sobre el qual no es disposi de drets suficients. Les imatges generades amb IA no es consideren automàticament protegibles.

Consulta les [condicions i exclusions](docs/llicencia.md) i l'[inventari de recursos](docs/inventari-visual.md).
